# Not used. The serverless dependency set lives in `pyproject.toml`.
#
# This file is kept as a signpost rather than deleted, because "a
# requirements.txt next to the entry point" is the first place anyone looks
# when a Python deployment is missing a package -- and finding nothing there is
# a worse outcome than finding this.
#
# Vercel's Python builder resolves `pyproject.toml` first and installs
# `[project].dependencies` with uv. Once a pyproject exists, a requirements
# file beside the entry point is not consulted at all. That is a change from
# the older builder, and the failure it produces is quiet: the build log says
# "Installing required dependencies from pyproject.toml", then "Build
# Completed" in about two seconds, and every request returns
# FUNCTION_INVOCATION_FAILED because fastapi was never installed.
#
# So the list is in `pyproject.toml`, under `[project].dependencies`, with the
# reasoning beside it. `req.txt` remains the source of truth for the container
# and for a local checkout; the serverless set is the smaller one, and the two
# must pin identical versions.
