# Dependencies for the Vercel function. NOT the same set as `req.txt`.
#
# Vercel's Python runtime installs the `requirements.txt` sitting next to the
# entry point in preference to the one at the repository root, which is the
# whole reason this file is here: the root set pins `sentence-transformers`,
# and that pulls torch. Measured on `python:3.13-slim`, torch from the default
# index is 1.2 GB plus 3.2 GB of `nvidia/` wheels -- so far over a serverless
# function's 250 MB unzipped limit that it is not a tuning problem, it is a
# different deployment.
#
# Everything heavy in this project is imported *inside* the function that needs
# it (`app/rag/clients.py` branches on the provider, `app/rag/loaders.py`
# imports pypdf only to read a PDF), so omitting a package here degrades one
# capability rather than breaking the import. That property is what makes this
# file viable at all, and it is worth not breaking: a module-scope
# `import langchain_huggingface` anywhere under `app/` would turn every cold
# start on this platform into a crash.
#
# Pinned to the same versions as `req.txt`. Two files pinning one dependency to
# two versions is how a bug reproduces in one deployment and not the other.

# --- The import graph at module scope ----------------------------------------

# anything. Nothing below this group is needed for the process to start.

# --- Providers ---------------------------------------------------------------
# Imported lazily. A missing one costs the capability it serves, not the
# deployment:
#   no langchain-openai   -> EMBEDDING_PROVIDER=openai and LLM_PROVIDER=openai fail
#   no langchain-pinecone -> effective_retrieval_mode resolves to lexical
#   no langchain-groq     -> LLM_PROVIDER=groq fails; a caller's own key still works
#   no langchain-tavily   -> the web fallback is off; the private KB is unaffected
openai==3.3.1
langchain-openai==1.6.0
langchain-pinecone==0.2.13
pinecone==7.3.0
langchain-groq==1.1.3
langchain-tavily==0.2.18

# --- Uploads -----------------------------------------------------------------
# Small, and the admin upload path is one of the things worth demonstrating.
# Note that an upload on this platform lands in /tmp and is indexed into
# Pinecone -- the vectors persist, the file does not.
pypdf==6.16.2
python-docx==1.2.0

#   `scripts/ingest_public_web.py` uses. Ingest is not a thing a serverless

#   Pinecone index this reads from.
# uvicorn -- the platform provides the server; this exports an ASGI app.
